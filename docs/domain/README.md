# domain/ — ドメイン情報（マスタ情報）

システムの **恒久的な定義** を置くディレクトリ。仕様・構造・モデルなど、
特定の日付や一時的な作業に依存しない「マスタ情報」をここで管理する。

開発時・修正時の一時的な情報（調査メモ・バグ分析・検討中の修正案・タスク引き継ぎ）は
[../flow/](../flow/) に分離している。

| ファイル | 内容 |
|---------|------|

| [domain-model.md](./domain-model.md) | ドメインモデル（エンティティ定義・パイプラインフェーズ・レンダリング層） |
