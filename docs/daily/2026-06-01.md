#### [Claude Design Anthropic Labs](https://www.anthropic.com/news/claude-design-anthropic-labs)
<sub>anthropic-blog ・ 2026-05-28 ・ 継続話題（7回目）</sub>
<sub>**訳**: Anthropic Labs による Claude Design の紹介</sub>

Anthropic Labs が Claude Design を発表した。発表日は 2026年4月17日。Claude Opus 4.7 を搭載したビジュアル制作ツールで、デザイン・プロトタイプ・スライド・ワンページャーなどの視覚的成果物を Claude と協働して作成できる。Claude Pro、Max、Team、Enterprise の各サブスクライバー向けにリサーチプレビューとして段階的に提供している。

オンボーディング時に、ユーザーのコードベースおよびデザインファイルを読み込み、チームのカラー・タイポグラフィ・コンポーネントを含むデザインシステムを自動構築する。以降のプロジェクトにはそのシステムが自動適用され、チームは複数のデザインシステムを管理することもできる。

入力形式はテキストプロンプト・画像・文書（DOCX、PPTX、XLSX）・コードベースの指定・Webキャプチャツールによる既存サイトの要素取り込みに対応する。出力後はインラインコメント・テキスト直接編集・調整ノブ（Claude が生成するカスタムスライダー）でスペース・カラー・レイアウトを細かく変更し、変更をデザイン全体に一括適用するよう Claude に指示できる。

共有はOrganizationスコープで管理され、非公開・組織内リンク共有・編集権限付与の3段階を選べる。グループ会話で複数メンバーが同時に Claude とチャットしながら編集することも可能。エクスポート形式は組織内URL・フォルダ・Canva・PDF・PPTX・スタンドアロンHTMLに対応する。

主な用途として挙げられているのは、静的モックアップからインタラクティブプロトタイプへの変換（コードレビュー不要）、PM による機能フローのワイヤーフレーム作成（Claude Code へのハンドオフまたはデザイナーへの引き渡し）、デザイナーによる方向性探索、ファウンダーや営業担当による粗い概要からの完成ピッチデッキ生成（PPTX またはCanva へのエクスポート対応）、マーケターによるランディングページ・SNSアセット・キャンペーンビジュアルの作成、そして音声・映像・シェーダー・3D・内蔵AI を活用するコード駆動プロトタイプ（フロンティアデザイン）の構築である。

デザインが完成したら、Claude がすべての内容をハンドオフバンドルにまとめ、Claude Code での実装に引き渡す機能も備える。

#### [Guidelines for Respectful Use of AI](https://www.elidedbranches.com/)
<sub>hacker-news ・ 3pt ・ 2026-05-31</sub>
<sub>**訳**: AI の礼儀ある使い方のガイドライン</sub>

「Elided Branches」ブログの著者が、チーム全体の文脈における AI ツールの礼儀ある使い方についてのガイドラインを提唱した。企業が AI ポリシーを策定する際、セキュリティ・コンプライアンス・コスト面には注力する一方、チームとして AI をどう使うべきかという観点が軽視されているという問題意識から書かれている。

著者が挙げる「礼儀ある AI 使用」の要素は以下のとおりである。まず、自分がレビューしていないものを他者にレビュー依頼しないこと。AI でコードを生成しそのまま提出した場合、レビュアーはプロンプトが適切だったか・AI がコンテキストを正しく理解したかを両方検証しなければならず、同僚に大きな検証コストを押しつけることになる。文書はコードより誘惑が大きく、AI に質問して回答をスキャンし文書化してそのまま送るケースが多いが、頭の中にある文脈が文書に反映されていないことに気づかないまま送信してしまう危険がある。生成された文書について会話できない・内容を説明できない場合は、少なくとも「AI 生成であり自分はこの分野をまだ理解できていない」という注記なしに送るべきではないと著者は述べる。

また、短い方が良いという原則も挙げている。AI は冗長な出力を生成しやすく、レビュー負担が増す。本文は途中で切れており（bodyTextが途中で終了）、続きのガイドライン項目は本文中で確認できない。
