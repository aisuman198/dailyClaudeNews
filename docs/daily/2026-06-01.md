<sub>anthropic-blog ・ 2026-05-27 ・ 継続話題（4回目）</sub>
<sub>**訳**: Claude Code オートモードの構築方法：パーミッション省略のより安全な方法</sub>

Anthropic のエンジニアリングブログが、Claude Code オートモードの技術的詳細を公開した。Claude Code のデフォルト動作ではコマンド実行やファイル変更のたびにユーザーの承認を求めるが、テレメトリによれば 93% のプロンプトがそのまま承認されており、承認疲れを招いていた。オートモードはモデルベースの分類器に承認判断を委譲することで、手動レビューと無制限実行の中間に位置する安全策を提供する。

過去のインシデントとして記録されているものには、誤解釈された指示によるリモート git ブランチの削除、エンジニアの GitHub 認証トークンの内部クラスターへのアップロード、本番データベースへのマイグレーション試行がある。

Netflix のシニアエンジニア Tejas Chopra が、エージェント命令をトークン単位で削減するオープンソースソフトウェア「Project Headroom」を開発した。Chopra はトークンの最大 90% が LLM に対して冗長であると見積もっている。
