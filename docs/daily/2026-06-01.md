Anthropic は Claude Code に Dynamic Workflows を導入した。複雑なレガシーコードベース全体にわたるバグ調査、数百ファイルにまたがるマイグレーション、多角的な検証が必要なプランニングなど、単一エージェントの 1 回の処理では対応困難な規模の問題をエンドツーエンドで処理するために設計されている。

#### [How we built Claude Code auto mode](https://www.anthropic.com/engineering/claude-code-auto-mode)
<sub>anthropic-blog ・ 2026-05-27 ・ 継続話題（9回目）</sub>
<sub>**訳**: Claude Code の Auto Mode 構築の経緯 — 権限スキップをより安全に行うしくみ</sub>

Anthropic のエンジニアリングブログが Claude Code Auto Mode の技術的構成を解説した。

Claude Code のデフォルトではコマンド実行・ファイル変更前にユーザーの承認を求めるが、ユーザーはプロンプトの約 93% を承認しており、承認疲労が問題となっていた。既存の回避策としては、ツールをホストから分離するサンドボックス（高メンテナンスコスト）と、すべての権限プロンプトを無効化する `--dangerously-skip-permissions` フラグ（保護なし）があり、Auto Mode はこの中間としてモデルベースの分類器（classifier）に承認判断を委譲する仕組みとして設計された。
