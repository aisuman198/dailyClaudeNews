プログラムを立ち上げた背景として、AI システムが仕事・学習・問題解決の中心となっている一方、会話の相手や感情的サポートの源にもなっている実態を挙げている。ユーザーが AI に孤独感の解消を求めたり、メンタルヘルス危機を乗り越えるために利用したりする場面でのモデルの振る舞いについて、業界全体での明確な基準がまだ整備されていないとしている。

Anthropic の Safeguards チームによるガイダンスも公開されており、有用なウェルビーイング評価の要件として、測定対象の明確化、臨床・専門家の設計・検証への関与、過剰対応と拒否過剰の両リスクの評価、実際のユーザー利用を反映した複数ターンの会話シナリオの構築、採点者の実専門家による検証、の5点を挙げている。

#### [Claude Code の利用実態：エージェント型コーディングと専門知識の持続的効果（2026年6月）](https://www.anthropic.com/research/claude-code-expertise)
<sub>anthropic-blog ・ 2026-08-25</sub>
<sub>**原題**: Claude Code Expertise</sub>

2025年10月〜2026年4月の約40万件の Claude Code セッション（約23万5千人）を対象にした分析結果を公開した。典型的なセッションでは、人間が計画に関するほとんどの判断（何をするか）を行い、Claude が実行に関するほとんどの判断（どのようにするか）を行うという分業が成立している。利用者のドメイン専門知識が高いほど、1命令あたり Claude がこなす作業量が増える。

コーディングタスクにおいて、ほぼすべての主要職種の利用者が、ソフトウェアエンジニアとほぼ同等の成功率（パステストやコミット済み成果物などで確認できる達成）を示している。中級者と上級者の成功率の差は小さく、ドメインへの習熟があれば深い専門知識を持つ者とほぼ同等に活用できることが示されている。

7か月の観察期間において、デバッグに費やすセッションの割合はほぼ半減し、コードのデプロイ・実行、データ分析、非コードドキュメント作成といった、よりエンドツーエンドのエージェント型用途へとシフトした。フリーランス求人との比較で推計した典型的タスクの価値は、ほぼすべての種別で平均約25%上昇した。GitHub プロジェクトにおいてコーディングエージェント活動を持つプロジェクトの割合は2025年末以降に2倍以上となり、Claude Code ユーザーは週平均20時間ツールを利用しているとしている。

#### [81,000人の Claude ユーザー調査：AI と雇用・生産性に関する意識（2026年4月）](https://www.anthropic.com/research/81k-economics)
<sub>anthropic-blog ・ 2026-08-25</sub>
<sub>**原題**: What 81,000 people told us about the economics of AI</sub>

Claude ユーザー81,000人を対象に実施した調査の結果を公開した。AI にさらされている度合いが高い職種の回答者ほど、AI による雇用喪失への懸念が高い。この傾向はキャリア初期の回答者にも同様に見られる。最高報酬と最低報酬の職種の回答者が最大の生産性向上を報告しており、その内容として「新しいタスクができるようになった（範囲の拡大）」が最も多く挙げられている。AI による最大の速度向上を経験している回答者ほど、雇用喪失への懸念も高い。

#### [Claude Code v2.1.245：glibc 2.44 環境での起動クラッシュを修正](https://qiita.com/picnic/items/18a1cc9c54a77605c0ea)

Claude Code v2.1.245 は、glibc 2.44 を採用する Linux ディストリビューション（Arch Linux・CachyOS・Fedora Rawhide 等）で Claude Code CLI が起動時にクラッシュするという重大な不具合を修正したリリース。対象環境では Claude Code はインストールできても起動直後にクラッシュし、実質的に利用不能な状態となっていた。CI パイプラインやコンテナイメージで固定バージョンを使っている場合、glibc のバージョン更新のタイミングで突然この問題に遭遇する可能性があるとしている。
