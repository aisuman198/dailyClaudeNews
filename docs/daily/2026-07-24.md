#### [Claude Opus 4.7 の提供開始](https://www.anthropic.com/news/claude-opus-4-7)

<sub>**原題**: Introducing Claude Opus 4.7</sub>
<sub>関連: https://www.anthropic.com/news/claude-opus-4-5 ・ https://www.anthropic.com/news/claude-opus-4-8 ・ https://www.anthropic.com/news/claude-opus-4-6</sub>

Anthropic が Claude Opus 4.7 を一般提供開始した。Opus 4.6 に対して高度なソフトウェアエンジニアリング能力が向上しており、特に難易度の高いタスクで大幅な改善が見られると説明されている。ユーザーからは、以前は綿密な監視が必要だった最難レベルのコーディング作業を Opus 4.7 に任せられるという報告が挙がっている。

モデルの主な特徴として以下が挙げられている。

- 複雑で長期にわたるタスクを厳密かつ一貫して処理する。
- 指示への精密な注意と、報告前に自身のアウトプットを検証する仕組みを持つ。
- より高解像度で画像を処理できる vision 能力の大幅な向上。
- インターフェース・スライド・ドキュメントなど、プロフェッショナルな成果物の品質向上。

サイバーセキュリティ対応について、Anthropic は Claude Mythos Preview のリリースを引き続き限定的に維持しながら、より能力の低いモデルで新たなサイバー保護機能をテストする方針を採ると説明している。Opus 4.7 はその最初のモデルとなる。Opus 4.7 のサイバー能力は Mythos Preview ほど高度ではなく、訓練段階でこの差を意図的に設ける試みが行われた。禁止またはリスクの高いサイバーセキュリティ用途を示すリクエストを自動検出・ブロックする保護機能を搭載したうえでリリースされる。脆弱性調査・ペネトレーションテスト・レッドチーミングなど正当なサイバーセキュリティ目的での利用を希望するセキュリティ専門家向けに Cyber Verification Program が新設された。

提供先は Claude の全製品・API・Amazon Bedrock・Google Cloud の Vertex AI・Microsoft Foundry。価格は Opus 4.6 と同額で、入力 $5/百万トークン、出力 $25/百万トークン。API からは `claude-opus-4-7` で利用できる。

早期アクセステスターからは「計画段階で論理的欠陥を自ら検出し実行を加速する」「非同期ワークフロー・CI/CD・長期タスクの処理に優れる」「データが欠落している場合にもっともらしい誤りを提供せず正直に報告する」「ユーザーに単に同意するのではなく、より意見を持った視点をもたらす」といったフィードバックが寄せられている。

#### [claude-thermos: Claude セッションのプロンプトキャッシュを維持するツール](https://github.com/izeigerman/claude-thermos)
<sub>hacker-news ・ 51pt ・ 2026-07-23</sub>
<sub>**原題**: Show HN: Claude-thermos – keeps your Claude session warm for you</sub>

`claude-thermos` は Claude Code のプロンプトキャッシュが無効化されることによるコスト増を防ぐ Python 製の OSS ツール。

**問題の背景**: Claude Code のプロンプトキャッシュは 5 分の TTL を持つ。会話履歴はキャッシュから 0.1 倍の入力価格で読み込まれるが、5 分以上リクエスト間隔が空くとキャッシュが失効し、履歴全体が 1.25 倍の書き込みレートで再エンコードされる。この失効の主な原因はユーザーの思考時間ではなく、メインエージェントが 5 分以上かかる subagent の処理完了を待っている間に発生する。subagent はシステムプロンプト・ツールセットが異なるため、そのリクエストはメインエージェントのキャッシュプレフィックスを更新しない。subagent の処理が終わってメインエージェントが再開すると、内容が同一のまま追記されただけの履歴に対してキャッシュが消えており、20 万〜50 万トークンの再エンコードが発生する。約 185 のローカルセッションを計測したところ、この再ビルドがコスト全体の約 22% を占めたとされる。

**動作の仕組み**: `claude-thermos` は小さなローカルリバースプロキシとして起動し（`ANTHROPIC_BASE_URL` をループバックポートに向け、実際のトラフィックは Anthropic API にそのまま転送する）、`/v1/messages` のトラフィックを監視してセッションとリネージ（モデル＋ツールセット＋システムテキストで識別するキャッシュプレフィックス）にグルーピングする。メインエージェントが一定時間（デフォルト 270 秒）以上アイドル状態になると、バックグラウンドでキャッシュを維持するウォームアップが自動実行される。

**使い方**: Python 3.11 以上と `claude` CLI が必要で、`uvx claude-thermos` で通常の `claude` コマンドを置き換えるだけで動く。任意のオプションはそのまま通る。`CLAUDE_WARMER_DISABLE=1` を設定すると個別に無効化できる。調整パラメーターとして `--idle`（デフォルト 270 秒）・`--interval`（デフォルト 270 秒）・`--max-cycles`（デフォルト 4）・`--subagent-window`（デフォルト 540 秒）が用意されている。

#### [Claude Design 使用感 — ゼロから始める AI システム開発 #28](https://qiita.com/shominai2024/items/c0323c9473d9b1c8ed11)
<sub>qiita ・ 2026-07-23</sub>

Qiita ユーザー shominai2024 による Claude Design のレビュー記事。

Claude Design は 2026 年 4 月 17 日に Anthropic Labs から公開されたベータ版のデザインツール。Claude Pro 以上の課金ユーザーが Web 版・デスクトップ版の Claude から利用できる（記事執筆時点では英語版のみ）。画面は左のチャットと右のキャンバスに分割されており、自然言語で指示することで Web ページ・アプリ画面・ダッシュボード・プレゼン資料・インタラクティブな UI などを生成できる。一枚絵を生成する AI とは異なり、テキスト・ボタン・グラフなど複数の要素から成る構造を持つビジュアルの生成を得意とし、十数種類のテンプレートが用意されている。

著者が試した主なユースケースは以下の通り。

**1. 自然言語での Web サイト案作成**: イベントのランディングページを作成する例を示した。テイストを選択して第一稿を生成後、自然言語で色や構造を微調整できる。カラーリング変更は 5 時間リミットの 3% の消費にとどまった。キャンバス右上の編集アイコンから直接 HTML 構造を操作することも可能だが、Web の知識がない素人には難しいと著者は述べている。コメント機能で特定の要素をクリックして修正指示を出すことも可能。

**2. 既存の画像・資料を参考にした名刺作成**: 参考画像のテイスト（色・余白・雰囲気）を反映して名刺を作成できる。ラスター画像の生成は行えないが、ベクター的な表現で再現を試みる。消費は 5 時間リミットの 2%。

**3. デザインシステムを活用したダッシュボード作成**: 既存のコード・スライド・ブランド資料・配色資料を読み取ってデザインシステムを生成でき、一度作成したデザインシステムは再利用可能。毎回同じ説明をせずとも組織内で共通のルールに沿ったデザインを作成できる。

出力フォーマットは ZIP・PDF・PPTX・単体動作 HTML・Canva・Claude Code など複数の形式に対応し、閲覧・コメント・編集の権限付きリンク共有も可能。全体のテイストを大幅に変える可能性がある場合はまずトップページのみ作成してテイストを固め、その後ほかの部分を生成するのが効率的とされている。リリース当初よりコスパが向上したとの記述がある。入力可能なファイル形式として DOCX・PPTX・XLSX・画像・コードが挙げられており、既存の Web サイトから要素を取り込んだりコードを参照させたりすることもできるとされている。

#### [Claude Code がデスクトップアプリに！PC 閉じても動く新機能 Routines とは？](https://qiita.com/kinamocchi_tech/items/4a4a496f2bab52868f5a)
<sub>qiita ・ 2026-07-23</sub>

Qiita ユーザー kinamocchi_tech による Claude Code デスクトップアプリ刷新と Routines 機能の解説記事。

2026 年 4 月 14 日に Anthropic が Claude Code デスクトップを大幅刷新した。対応プランは Pro・Max・Team・Enterprise で、Mac・Windows・Linux の 3 プラットフォームに対応する。公式ブログには「orchestrator seat」という表現が使われており、VentureBeat はこれを「mission control」や「哲学的シフト」と表現したとされる。

追加された 8 つの機能は以下の通り。

1. **サイドバー**: プロジェクト一覧と会話履歴が左カラムに常時表示される。
2. **ドラッグ＆ドロップレイアウト**: パネルを自分の使いやすいように並べ替えられる。
3. **統合ターミナル**: アプリ切り替えなしでコマンドを実行できる。
4. **ファイルエディタ**: コードを UI 内で直接開いて編集できる。
5. **Diff Viewer**: AI が変更した箇所を変更前後で色付きで並べて表示できる。
6. **拡張プレビュー**: 画像や Markdown などのリッチコンテンツをその場で確認できる。
7. **Side Chat**: `Cmd+;` で別の会話をサイドで開きながらメインの作業を継続できる。
8. **View モード**: Verbose・Normal・Summary の 3 種類で表示情報量を選べる。

同じ日に発表された Routines は「保存された Claude Code の設定」であり、プロンプト・リポジトリ・コネクターの 3 要素をひとつにまとめて自動実行する仕組み。PC を状態でも動作させられる機能として紹介されており、設定を保存しておくことで繰り返しのタスクを自動で実行できる。
