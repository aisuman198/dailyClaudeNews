#### [Claude Fable 5 API移行チェックリスト：拒否処理・Adaptive Thinking常時オン・データ保持30日の実装対応](https://qiita.com/YushiYamamoto/items/dec0bf1e3c8556de9eb7)
<sub>qiita ・ 2026-06-18</sub>

2026年6月9日にAnthropicがClaude Fable 5（モデルID: `claude-fable-5`）をClaude API・Amazon Bedrock・Vertex AI・Microsoft Foundryで一般提供を開始した。コンテキスト1Mトークン・最大出力128kトークン・料金は入力$10/MTok・出力$50/MTokという仕様で、Anthropicが「最も要求の厳しい推論と長期エージェント作業向け」と位置付ける最上位モデルとされる。Opus 4.7で導入された新トークナイザーをFable 5も採用しており、同一テキストでも旧モデルと比べてトークン数が約30%増加する点が公式ドキュメントに記載されている。

本記事は既存のOpus系モデルからFable 5へ移行する際の3つの破壊的変更を整理している。

**1. Safety classifierによる拒否**：Fable 5はSafety classifierを内蔵しており、一部リクエストを拒否する。拒否時はエラーではなくHTTP 200として`stop_reason: "refusal"`が返る。`stop_reason`チェックが未実装の場合、拒否を正常レスポンスとして誤処理するリスクがある。拒否されたリクエストには課金されない。対応方法として、サーバーサイドfallbacksパラメータ（β、Claude API・Claude Platform on AWSのみ）・クライアントサイドfallback（SDKミドルウェア、TS/Python/Go/Java/C#対応、全プラットフォーム利用可）・手動retryの3通りが整理されている。別モデルにretryする場合はプロンプトキャッシュコストの二重払いを防ぐ「fallback credit」が適用される。なおClaude Mythos 5（招待制）はSafety classifierなしで同一スペックとされている。

**2. Adaptive Thinking常時オン**：Fable 5では`thinking: {"type": "disabled"}`が使用不可で、Adaptive Thinkingが唯一のモードとして常時適用される。`thinking`パラメータ未設定の場合も自動有効化される。生のチェーン・オブ・ソート推論は返却されず、`thinking.display`を`"summarized"`に設定することで推論の要約を取得できる。thinking深度の制御は`effort`パラメータで行う。マルチターン会話でthinkingブロックを返す場合は変更せずにそのまま渡す必要がある。

**3. データ保持30日・ゼロデータリテンション（ZDR）対象外**：Fable 5とMythos 5はCovered Modelsに指定され、30日間のデータ保持が適用される。ZDR必須の医療・法務・金融等の用途では使用不可となる。

#### [Claude Code v2.1.181 の新機能・バグ修正まとめ ─ /config 構文と重大バグ修正](https://qiita.com/picnic/items/5dbedcdd25053ee70eb5)
<sub>qiita ・ 2026-06-18</sub>

Claude Code v2.1.181がリリースされた。日常的な開発作業に直結する重大バグの複数修正を含む重要リリースとされている。

**新機能**として、プロンプトから設定を直接変更できる`/config key=value`構文が追加された（例：`/config thinking = false`でthinkingをオフ、`/config model = claude-opus-4-8`でモデル切替）。インタラクティブモード・`-p`モード・リモートコントロールのいずれでも動作する。また`CLAUDE_CLIENT_PRESENCE_FILE`環境変数が追加され、マーカーファイルを指定することでユーザーがPCを使用中にモバイルへのプッシュ通知を抑制できる。macOS向けには`sandbox.allowAppleEvents`オプションでサンドボックス内コマンドからのApple Events送信が可能になった。

**改善点**として、Bunランタイムが1.4にアップグレードされパフォーマンスが向上。長い段落でも最初の改行を待たずに行単位で逐次ストリーミング表示されるよう改善された。思考中のAPI切断時は自動でリトライするようになった。MCP OAuth UIがClaude Codeのデザインに統一され、認証成功時にブラウザタブが自動で閉じるようになった。サブエージェントパネルはアイドル状態のエージェントを30秒後に自動非表示・リスト最大5行に制限された。

**重大度高のバグ修正**は次の通り。起動時のハング・クラッシュ・遅延について複数の問題が修正された：v2.1.169で混入した120msのリグレッション、劣化ネットワーク環境での最大15秒の起動ブロック、`.claude.json`に破損したnullエントリがある場合のTypeErrorクラッシュ、macOSでSpotlight再インデックス中にClaude Codeが起動時フリーズしCtrl+Cも無反応になる問題。セッション履歴の消失（長時間アイドルのセッションで別プロセスが30日分のトランスクリプトクリーンアップを実行したタイミングで会話履歴が消える問題）も修正された。OneDrive・Dropbox・NAS等のクラウド同期フォルダやネットワークドライブ上でWrite/Editを実行すると0バイトまたは切り詰められたファイルが生成される問題もこのバージョンで修正されており、該当環境を使用していた場合は過去に生成されたファイルをgitやバックアップから確認することが推奨されている。

**中程度のバグ修正**として、カスタム`ANTHROPIC_BASE_URL`やFoundry環境でリクエストごとに変わる証明トークンが原因でプロンプトキャッシュが機能しない問題、AWS BedrockのawsCredentialExportで残存有効期間が短い認証情報が毎分リフレッシュを引き起こす問題、`claude mcp get`/`claude mcp list`でtoolsフェッチ失敗時も「✓ Connected」と誤表示される問題が修正された。

**破壊的変更**として、フルスクリーンモードでのURL開放がCmd+クリック（macOS）/ Ctrl+クリック（Windows・Linux）必須に変更され、従来のシングルクリックでは開かなくなった。
