#### [Claude Fable 5.1 と Claude Mythos 5.1 の発表](https://www.anthropic.com/claude-fable-and-mythos-5-1)
<sub>hacker-news ・ 1373pt ・ 2026-09-01 ・ 継続話題（2回目）</sub>
<sub>**原題**: Claude Fable 5.1 and Claude Mythos 5.1</sub>
<sub>関連: https://qiita.com/picnic/items/01982e38dbe329f13bae</sub>

Anthropic は Claude Fable 5.1（`claude-fable-5-1`）と Claude Mythos 5.1（`claude-mythos-5-1`）を公開した。両モデルは同一の基盤モデルで、Fable 5.1 は一般公開、Mythos 5.1 は信頼アクセスプログラム（Project Glasswing）参加者向けに提供される。Mythos 5.1 のセーフガードはサイバーセキュリティとライフサイエンス分野での利用を想定した設計になっている。

**コスト・仕様**

デフォルトで 1M トークンコンテキスト、最大 128k 出力トークン、常時オン（手動無効化不可）の adaptive thinking をサポートする。入力・出力料金は Fable 5 と同額の $10 / $50 per MTok。プロンプトキャッシュ読み取りは $0.25 per MTok で、他モデルのベース入力比 0.1 倍に対して 0.025 倍と大幅に安い。この価格差により、典型的なワークロードで Fable 5 比約 25%、長いコンテキストを繰り返し参照するエージェント用途では最大約 45% のコスト削減となる。

Fable 5.1 は Medium エフォート設定時に Fable 5 の High エフォート相当以上の性能を発揮するとしている。Claude Code ではデフォルト High、Claude Cowork と claude.ai ではデフォルト Medium で動作する。

**セーフガード改善**

サイバーセキュリティ分野では誤検知（良性コンテンツへの誤フラグ）を以前比 60% 削減した。Fable 5.1 はソフトウェア脆弱性の発見には利用できるが、エクスプロイトの開発には使用できない。生物学分野では米国政府と連携した Mythos 5.1 の高度な生物学機能へのアクセスプログラムを設立し、科学者向けに近日中に登録受け付けを開始するとしている。

**データ保持**

EFS（Enterprise Frontier Safeguards）が顧客のクラウドインフラ内にデータを保管する新体系として準備中。EFS の展開開始までの間は、対象顧客が Fable 5.1 をゼロデータリテンションで利用できる。完全な EFS 提供前は 30 日間のデータ保持が必須（ゼロデータリテンション非対応）。

**科学研究での実証**

分子設計の分野では、Mythos 5.1 にオープンソースのタンパク質設計・折り畳みツールへのアクセスを与え、その設計を外部 2 機関で実験的に検証した。12 のターゲットに対するヒット率（有効なバインダーとして確認された設計の割合）は約 50%に達した（現在の業界標準は 10〜15%）。3 つのターゲットでは Adaptyv Bio のタンパク質設計コンペティション最高設計と比べ結合親和性が 10 倍高い結果を示した。

計算科学の分野では、Fable 5.1 が NASA のマゼラン探査機から 30 年以上前に取得したレーダー画像をもとにニューラルネットワークを訓練し、金星の北 3 分の 1 を新たにカバーする高解像度地形図（解像度 300m）を作成した。従来の精度 10〜20km から 2〜3km へ改善し、高さの精度も最大 25% 向上した。クリエイティブコモンズライセンスで公開予定。

計算生物学の分野では、Mythos 5.1 がカスタム GPU カーネルと中間結果のキャッシュを活用し、オープンソースの深層学習モデル 7 種類（ChromBPNet・Flashzoi・Enformer・Profluent-E1・ProGen2・Evo 2 など）を最大 2.5 倍に高速化した。ゲノム全体解析での推定 GPU コストを 30〜60% 削減できるとしている。通常はパフォーマンスエンジニアチームが数週間かける最適化を数日で実施した。投資会社 Millennium のシニアポートフォリオマネージャーは「4〜5 年間、エンジニア全員と他のすべてのモデルが原因を特定できなかった約 100 万回に 1 回のシステムクラッシュを Fable 5.1 が初めて特定した」とコメントした。

**API 開発者向けの破壊的変更**

Fable 5.1 / Mythos 5.1 への移行に伴い、以下の変更が加わっている。

`tool_choice: {"type": "any"}` および `{"type": "tool"}` が廃止され、Fable 5.1 / Mythos 5.1 に対して指定すると 400 エラーが返る。代替として strict tool use または structured outputs への移行が必要。

Python SDK v1.0 では `httpx` から `httpx2` へ移行し、Python 3.10 以上が必須となった。Text Completions API および `temperature`/`top_p`/`top_k` 等のパラメータが削除された。

旧モデルの退役スケジュールは以下の通り：Claude Haiku 3（2026-04-20）、Claude Sonnet 4 / Opus 4（2026-06-15）、Claude Opus 4.1（2026-08-05）。退役後の全リクエストはエラーになる。

#### [Enterprise Frontier Safeguards の顧客との共同開発](https://www.anthropic.com/news/enterprise-frontier-safeguards)

Anthropic は Enterprise Frontier Safeguards（EFS）を発表した。EFS はゼロデータリテンション（ZDR）と同等のプライバシーを、不正使用検知の自動セーフガードと組み合わせたソリューションで、データを Anthropic ではなく顧客が制御するクラウドインフラに保管する。秋以降に段階的に顧客へ展開する予定で、EFS 提供開始までの間は対象顧客が Fable 5 および Fable 5.1 をゼロデータリテンションで利用できる。

金融・医療・製造・通信・法律・小売・公共部門など幅広い業種の 100 社超の顧客、および AWS・Google Cloud・Microsoft Azure のクラウドパートナーと共同で設計した。Claude Code・Claude Enterprise・Claude Platform・Amazon Bedrock・Google Agent Platform・Microsoft Foundry でサポートされる。

**開発の背景**

Anthropic は Fable 5 から 30 日間のデータ保持ポリシーを導入した。これはエンタープライズデータへのトレーニングが目的ではなく（Anthropic は明示的な許可なしにエンタープライズデータでのトレーニングを行ったことはないとしている）、高度な不正使用の検知には複数のセッション・アカウントにまたがる行動の相関分析が必要なためとしている。Anthropic によると、詐欺などの典型的な悪用から、認証情報の窃取を含む高度なサイバー攻撃まで多様な不正使用の試みが増加しているとしている。

**設計上の3つの柱**

監視の統制については、自動監視システムが不審なパターン（攻撃的なサイバー・生物兵器開発の試み、認証情報の漏洩・窃取の兆候など）を検知した際、フラグが顧客に直接送信され、顧客チームが対応する。Anthropic の従業員による人手のレビューは不要。

データの保管場所については、活動データを顧客自身のクラウドアカウント（Amazon S3・Azure Blob Storage・Google Cloud Storage など）に保管できる。顧客が管理する暗号化キー・アクセスポリシー・監査ログの下で管理される。

人手レビューの統制については、Anthropic による人手レビューは発生しない。規制上の機密情報（特権法的資料・非公開情報・薬品安全報告など）を扱う顧客を中心に、この点が強く求められた。

Customer-owned storage・Customer-Managed Encryption Keys・完全自動レビューはそれぞれオプトインで有効化でき、モデルの挙動・API 料金・レート制限に影響しない。EFS に対して Anthropic は料金を徴収せず、顧客のクラウドプロバイダーがストレージ利用分を通常通り課金する。
