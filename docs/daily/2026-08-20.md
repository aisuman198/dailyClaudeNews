#### [Claude Code v2.1.235：権限プロンプトの安全性修正と機能改善まとめ](https://qiita.com/picnic/items/8a8fedd55552da4bc86c)
<sub>qiita ・ 2026-08-19</sub>

Claude Code v2.1.235 が 2026 年 8 月にリリースされた。今回のアップデートは合計 19 件の変更を含む。

最重要の変更は権限プロンプトに関する安全性修正 2 件だ。1 件目は、権限プロンプトのコメント欄にフォーカスがある状態で Shift+Tab を押すと、本来は「欄を閉じる」操作のはずが意図せずセッション全体への編集権限を付与してしまう不具合の修正。2 件目は、権限ダイアログに表示されているテキストと実際に「今後確認しない」で付与される権限範囲が食い違うケースへの対処で、内容を完全に表示できない場合には「今後確認しない」オプション自体が表示されなくなった。

その他の修正・改善には以下が含まれる。言語サーバー（LSP）の切断・再接続でプロンプトキャッシュ全体が無効化されていたバグを修正し、トークンコストとレイテンシが改善された。/ultrareview や /autofix-pr 実行中のイベントストリーム再スキャンを廃止し、メモリ・CPU 使用量を削減した。組み込み grep は、病的な正規表現パターンでメモリを使い果たす前に失敗するよう修正され、-m N と -A/-C 併用時の出力も修正された。オプション機能として、aspell/hunspell/ispell を利用したプロンプト入力欄へのスペルチェック機能が追加された（デフォルト無効）。スペルチェックを有効化するには `~/.claude/settings.json` 等で `"spellcheck": true` を設定し、ローカルに aspell/hunspell/ispell のいずれかをインストールしておく必要がある。

UI/UX についても、ターミナル UI のネストされた Markdown リスト表示、複数行プロンプトのシンタックスハイライトのずれ、タスクリストの展開状態保持、Vim モードのカーソル位置保持、VS Code 拡張でのフォーカス管理など細かな不具合修正が複数含まれている。

#### [Anthropic が AGENTS.md のサポートを拒否](https://github.com/anthropics/claude-code/issues/6235)
<sub>hacker-news ・ 27pt ・ 2026-08-19</sub>
<sub>**原題**: Anthropic Refuses to Support Agents.md</sub>

Codex・Amp・Cursor など他のコーディングエージェントが AGENTS.md（https://agents.md/）への対応を進めている中、Claude Code に同ファイルのサポートを求めるフィーチャーリクエストが GitHub に投稿され、クローズされた。

リクエストの要旨は、AGENTS.md はコーディングエージェントがコードベースを理解するための統一 Markdown ファイルであり複数ツールにまたがる協働に適している一方、CLAUDE.md は Claude Code 固有の設定ファイルであるため、Claude Code を使わない開発者と協力する場面では機能しにくいという点だ。Issue は現在クローズ状態となっている。

**Anthropic の年換算売上が 650 億ドル超に**

Bloomberg と TechCrunch の報道によれば、Anthropic は投資家向けに 7 月末時点の年換算売上（run rate）が 650 億ドルを超えたと伝えた。6 月初旬に機密 S-1 で開示した 470 億ドルから約 38% 増、2026 年初頭の約 90 億ドルの約 7 倍にあたる。成長の軌跡は、2024 年初頭の約 8,700 万ドル → 2024 年末の 10 億ドル → 2026 年 4 月の 300 億ドル → 2026 年 5 月の 470 億ドル → 2026 年 7 月末の 650 億ドルと記録されている。牽引役は Claude Code で、2025 年 11 月に年換算約 10 億ドル、2026 年 2 月には約 25 億ドルに達し、Fortune 10 のうち 8 社が顧客となっている。

IPO については、投資家が今秋の上場で約 2 兆ドルの評価を目標としているとされ、2026 年 5 月の H ラウンド時の評価額 9,650 億ドルから大幅に上昇する計算となる。650 億ドルの run rate に対して 2 兆ドルとすると売上倍率は約 31 倍となる。記事は、run rate は好調な四半期の外挿であり監査済みの実績売上ではないと注記している。また Quartz によれば、輸出規制に関連して一部モデルの一時撤去や国防サプライチェーンリスク指定を経験したとも報じられている。

**Samsung が先端ファウンドリ価格を最大 15% 値上げ**

Reuters の報道によれば、Samsung Electronics は一部の先端受託製造サービスについて最大 15% の値上げを実施した。対象は 4nm・5nm・8nm プロセスで、一部の中国・米国顧客が最も大きな値上げに直面する。平沢の 4nm ラインはフル稼働状態とされる。中国のチップ設計企業は米国の輸出規制によりすでに先端装置へのアクセスが制限されており、より多くの設計が中国本土外のファウンドリに流れているとされる。

**世界ロボット大会 2026 が北京で開幕**

2026 世界ロボット大会（WRC）が 8 月 19 日、北京・亦庄で開幕した。373 社、約 3,000 点の展示品、311 件の初披露製品が並んだ。北京人形ロボット創新中心は家庭向け小型人形ロボット「天工 Omni」と具身マルチモーダル大モデル「Pelican-Unify 1.0」を発表。星海図は G0.5 具身基礎モデルを搭載したロボットが京東物流の実際の前線倉庫でピッキング・ナビゲーション・梱包・配置を自律実行するデモを実施した。宇樹科技の GD01 搭乗型メカ（3m・500kg・二足/四足切替）は量産済みで、小米も同大会でヒューマノイドロボットを初公開すると発表した。

#### [Claude Code に綺麗な日本語を書かせたい](https://qiita.com/megmogmog1965/items/4b668265025cf97ea843)

Claude Code が日常的に犯す日本語の問題を「文体の癖」と「文脈の崩れ」に分類している。文体の癖には、体言止め・くだけた語（「いじる」「ちょっと」等）・造語・略語・装飾的な前置き（「いよいよ〜」等）・実況中継調・メタディスコース・読者の反応の決めつけ・冗長な言い直しが挙げられている。文脈の崩れには、同一内容の重複・接続の乱れ・構成の崩れが挙げられており、いずれも文書全体を読まないと気づきにくく、修正も章立ての見直しに及ぶ場合があるとされている。
