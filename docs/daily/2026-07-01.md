Claude Code v2.1.197 で Claude Sonnet 5 がデフォルトモデル替わり、1M トークンのコンテキストウィンドウが追加設定なしで利用可能になった。プロモ価格（入力 $2・出力 $10/MTok）は 2026 年 8 月 31 日まで適用される。直前の v2.1.196 には安定性・セキュリティ面の修正が多数含まれる。

**セキュリティ修正（Breaking Change）**: リポジトリにコミット済みの `.claude/settings.json` が `.mcp.json` のサーバーを自己承認していた場合、`claude mcp list` や `claude mcp get` の実行だけで信頼していない MCP サーバーが自動起動していた問題が修正された。v2.1.196 以降、これらのコマンドは信頼されていないワークスペースでサーバーを起動せず、「⏸ Pending approval」と表示して手動承認を求める。他人のリポジトリをクローン後に `claude mcp list` を実行する運用をしている場合は動作変更に注意が必要。

**データ損失バグの修正**: バックグラウンドジョブを復帰させた際、トランスクリプトのプローブが正常なファイルを誤読し、会話履歴を完全削除したうえで元のプロンプトを再実行していたバグが修正された。v2.1.196 以降は問題のあるファイルは削除されず別の場所に退避される。

**ストリーム監視の全プロバイダ有効化**: 5 分間イベントが届かない応答ストリームを自動で中断・再試行するウォッチドッグが v2.1.196 からすべてのプロバイダでデフォルト有効化された。無効化する場合は `CLAUDE_ENABLE_STREAM_WATCHDOG=0` を設定する。

**MCP OAuth の `invalid_scope` 修正**: スコープ未指定の場合に認可サーバーの全スコープを要求してしまい、GitLab セルフホストや企業の IdP で認証エラーが発生していた問題が修正された。必要なスコープのみを要求するよう変更されている。

**組織デフォルトモデルの設定対応**: 管理者が org コンソールでデフォルトモデルを設定できるようになった。未選択時は `/model` に「Org default」と表示される。

**その他の主な変更（v2.1.196）**:
- 非 Anthropic ホスト使用時に Remote Control を自動無効化（Bedrock/Vertex との挙動を統一）
- `/code-review` のトークン使用量を約 25% 削減（5 つのクリーンアップファインダーを 1 つに統合）
- `--dangerously-skip-permissions` が無言で auto モードにフォールバックしていた問題を修正（免責表示と派生エージェントへの適用が正しく行われるように）
- バックグラウンドセッションがプロセス停止・再起動・更新をまたいで継続するよう改善（Windows 含む）
- PowerShell での `git diff` / `git grep` 等の exit 1 を失敗と誤判定していた問題を修正
- チャット添付ファイルを Cmd/Ctrl + クリックで Finder/Explorer に表示できるように

#### [Claude Code がプロンプトにステガノグラフィーマーカーを埋め込んでいることが判明](https://thereallo.dev/blog/claude-code-prompt-steganography)
<sub>hacker-news ・ 1247pt ・ 2026-06-30</sub>
<sub>**原題**: Claude Code is steganographically marking requests</sub>
<sub>関連: https://twitter.com/IntCyberDigest/status/2071971609183678544</sub>

Claude Code v2.1.196 のバイナリを調査したところ、システムプロンプト内の日付文字列を条件に応じて書き換えるコードが発見された。著者はこの技術を「プロンプトステガノグラフィー」と呼んでいる。見た目上は通常の日付文字列だが、生のリクエストにはマーカーが埋め込まれる仕組みになっている。

**変更の仕組み**: トリガーは環境変数 `ANTHROPIC_BASE_URL`。この変数が未設定の場合（通常の Anthropic API 使用時）は早期リターンして変更を行わない。変数が設定されている場合、以下の 2 つの条件を確認する。

1. **タイムゾーン確認**: システムタイムゾーンが `Asia/Shanghai` または `Asia/Urumqi` の場合、日付の区切り文字を `-` から `/` に変更する（例: `2026-06-30` → `2026/06/30`）。

2. **API ホスト確認**: `ANTHROPIC_BASE_URL` のホスト名をデコード済みのドメインリストおよび AI ラボキーワードリストと照合し、一致状況に応じて「Today's」のアポストロフィを異なる Unicode 文字に置換する:
   - 通常: `'`（U+0027）
   - 既知ドメイン一致: `'`（U+2019 右シングル引用符）
   - ラボキーワード一致: `ʼ`（U+02BC 修飾文字アポストロフィ）
   - 両方一致: `ʹ`（U+02B9 修飾文字プライム）

これらの文字は等幅フォントでは視覚的に区別できないため、ユーザーにもモデルにも通常の文字列に見える。ドメインリストとキーワードリストは base64 文字列として格納されており、キー 91 で XOR デコードされている。

この発見を受け、X（Twitter）の International Cyber Digest アカウントは「中国ユーザーを秘密裏に標的にするスパイウェア的なコード」との投稿を行い、1.5M ビュー・446 件の返信を記録した。同投稿は「ユーザーの信頼の深刻な侵害」と批判しており、タイムゾーン・プロキシ・AI ラボ接続に関する情報がユーザーの気づかない形でシステムプロンプトに注入されていると主張している。

#### [Claude を化学者に: NMR スペクトル解析能力の検証](https://www.anthropic.com/research/making-claude-a-chemist)

Anthropic の化学者 David Kamber が、化学者の日常的な分析入力の代表例として NMR スペクトルに対する Claude の性能を検証した研究。世界トップクラスの合成化学者・計算化学者・分析化学者と協力して Claude の化学能力を向上させる取り組みの一環として公開された。

化学者は手描き構造式・装置の出力・データベースクエリ・特許・学術誌の技術表記など複数の表現形式を行き来する。表現形式の違いは重大な帰結をもたらすことがある。グルコースとフルクトースは同じ分子式でも異なる代謝経路を持ち、サリドマイドは鏡像体反転によって鎮静剤が催奇形性物質になった。

化学分野では AI ツールがレトロシンセシス・反応予測・物性推定などに数年前から活用されているものの、利用率が一様でなく平均的な研究者には普及していない。その背景として、ヌル結果が少なく形式が不統一で購読誌のペイウォール内に閉じた学習データの不足が挙げられている。CAS（最大の化学物質登録機関）は 2 億 9,000 万以上の公開物質を収録し、毎日約 15,000 件ずつ増加している。

最新のフロンティアモデルはマルチモーダルかつ明示的な推論が可能で、論文の図や手描きスケッチから化学構造を直接読み取れるほか、手順書の実験詳細も理解でき、推論過程をステップごとに示すため化学者が出力を検証できる点が評価されている。Anthropic は Claude が翻訳・想起・統合作業で化学者を支援できるレベルに達しつつあるとしており、今後さらなる能力拡張を計画している。
