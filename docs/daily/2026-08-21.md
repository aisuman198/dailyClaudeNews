#### [Claude 5 のトークン出力を別の LLM で整形するツール「Vomit」](https://github.com/zachahn/vomit)
<sub>hacker-news ・ 161pt ・ 2026-08-20</sub>
<sub>**原題**: Vomit: Clean up Claude 5's token output with a separate LLM</sub>

Vomit は、Claude 5 が出力するトークン列を別のローカル LLM にパイプして人間が読める英語に変換する Go 製 CLI ツール。GNU GPLv3 ライセンスで公開されており、完全ローカル動作（テレメトリなし・外部依存なし）が特徴。

Claude Code の hooks 機能を利用して Claude の出力をリアルタイムで置き換えるモードと、サイドで並走して最新セッションを監視する非侵襲モード（`vomit tail`）の 2 種類の動作モードがある。対応 LLM は Llama.app、Ollama、OpenAI API 互換の実装。作者は初期導入先として GPT-OSS 20B（Llama.app 経由）を案内している。

制約として、ローカル LLM はあくまで Claude が出力しようとしたテキストのみを参照し、アクションやファイルへのアクセスはない。そのためハルシネーションが生じることがある。また現時点で Mac のみで動作確認済みであり、Claude のメッセージを完全に見落とす可能性もあると作者は注記している。元のメッセージを確認したい場合は AgentsView などを利用する方法を案内している。

#### [$27 のスマートウォッチ PineTime に Claude でウォッチフェイスを実装](https://www.mikekasberg.com/blog/2026/08/19/hacking-with-claude-on-a-27-smart-watch.html)
<sub>hacker-news ・ 78pt ・ 2026-08-20</sub>
<sub>**原題**: Hacking with Claude on a $27 Smart Watch</sub>

PineTime は 27 ドルのスマートウォッチで、オープンソースのファームウェア InfiniTime（あるいは任意の RTOS）が動作する。筆者は @steveruizok の ESP32 デバイスへのハッキング投稿に触発されて引き出しにしまっていた PineTime を取り出し、@levelsio の Apple Watch 向け Casio ウォッチフェイスに相当するものを PineTime 向けに作ることを目標に設定した。

実際の作業では「Claude」と呼んでいるものの、大半は OpenCode 上でオープンウェイトモデル（Kimi K3・K2.6、DeepSeek v4 Pro・Flash）を使って進めた。PineTime 向け開発に向いていると筆者が評価した理由として、価格が安いこと、ドキュメントが充実していてモデルの参照精度が高いこと、InfiniSim シミュレーターによる PC 上での高速フィードバックループが使えること、ファームウェアがシンプルで必要な機能を自分で追加していく構造であることを挙げている。

InfiniSim リポジトリをクローンしてビルドを通す作業は迅速に完了した。その後、@levelsio の投稿画像を参照として既存のウォッチフェイスのコードをベースに複製するよう指示し、サブエージェントを使ったオーケストレーションも依頼した。結果はある程度の近似にはなったものの、テキストのサイズや位置をモデルが推測で決めてしまったため、要素が重なって判読できない状態だったと報告している。Fable であればシミュレーターのスクリーンショットをフィードバックループに組み込めばピクセルパーフェクトに仕上げられた可能性があるとしつつ、予算の制約からオープンウェイトモデルを選択し、自分でより具体的なフィードバックを与えながら 1 要素ずつ修正する方針を取った。静的な部分をフルスクリーン背景画像にまとめ、動的部分だけをプログラムで描画するアイデアがシミュレーター上では有効だった。本文は途中で切れており、実機への書き込み後に判明した制約については記述が途切れている。

今回の更新では、レポート本文のページに「Related content（関連コンテンツ）」セクションが追加された。

1 つ目は「Claude によるタンパク質設計の加速」と題された記事で、Claude Opus 5（一般提供中のモデルとして言及されている）を使って生命科学研究者の研究速度を高める 2 つの実験結果を紹介している。一方はゼロからタンパク質バインダーを設計する能力のテスト（タンパク質系薬剤開発において従来は専門家が 1 ターゲットあたり数週間から数ヶ月を要していたとされる工程）、もう一方は NMR・LC-MS データを用いた化学分析の加速（化合物の同一性と純度の評価）についての評価。

2 つ目は「新興マルチエージェントシステムにおけるパターンと問題」と題された記事で、現在のフロンティアモデルに見られる行動傾向の例をいくつか示し、それが予期しない系統的な障害を引き起こすケースを報告している。これらのリスクを軽減するための議論の出発点とすることを目的として公開した、と説明されている。

3 つ目は「Claude の数学的能力についての詳細」で、未公開の研究版 Claude が Riemann 予想に関連する問題で進展を示したことが言及されている。具体的には、Riemann ゼータ関数のゼロ点のうち条件を満たす割合に関する長年の下界を改善したとされる。

レポート本体の内容は従来通りで、米国 56 件の無作為化研究と欧州の実験的エビデンスのメタ分析に基づき、就業訓練プログラムが平均的に雇用を 2〜3 ポイント・年収を約 1,000 ドル引き上げる一方、費用は約 1 万 3,000 ドルかかり、政府の回収分を含めればほぼ収支均衡に近いという知見を示している。ただし AI が大規模に労働者を代替する事態には既存プログラムでは対応が難しいと結論づけており、有望なプログラムの実証・評価・拡大を今すぐ始めることを中心的な提言としている。
