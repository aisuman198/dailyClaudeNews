#### [Claude のロボティクスタスク性能評価](https://www.anthropic.com/research/claude-plays-robotics)
<sub>anthropic-blog ・ 2026-08-26</sub>
<sub>**原題**: Claude Plays Robotics</sub>

Anthropic の Frontier Red Team が、複数の言語モデルをさまざまなロボットボディに接続し、古典制御問題・移動/ナビゲーション・マニピュレーションの3分野で性能を評価した研究を公開した（記載日：2026年7月9日）。

テスト対象のロボットボディは、古典制御玩具・シミュレーション上の四足歩行ロボット・ヒューマノイド・ロボットアーム・実機の Unitree Go2（四足歩行）を含む。制御インタフェースは抽象度の低い順に、(1) モータートルクの直接指令、(2) コントローラコードの記述、(3) 強化学習によるコントローラのトレーニング、(4) 事前学習済みロボットポリシーへの高レベル指示の4段階を用意した。

主な知見として、モデルのロボティクス性能はロボットボディと制御インタフェースの種類に大きく依存することが示された。最も抽象度の低い関節直接制御ではほぼ失敗するが、事前学習済みポリシーの監督や単純な方向指示ツールを使う場合は実際のナビゲーションおよびマニピュレーションタスクを完遂できる。ヒューマノイドボディは今日のモデルでは事前学習済みポリシーなしには制御できないが、新しいモデルが直接マニピュレーションとハイレベルポリシー制御で実質的な進歩を示している。ロボティクス専用トレーニングを受けていない汎用チャットモデルが、好調な実行では四足歩行ロボットを迷路内で歩かせたりカウンターから皿を取り上げてコンロに置くといったタスクを達成できたと述べられている。性能の評価には Anthropic が開発したベンチマークスイート Embody が使用された。本文は途中で切れている。

#### [言語モデルのキャラクタ特性を監視・制御するパーソナベクトル](https://www.anthropic.com/research/persona-vectors)
<sub>anthropic-blog ・ 2026-08-26</sub>
<sub>**原題**: Persona Vectors</sub>

Anthropic の解釈可能性チームが、AI モデルのニューラルネットワーク内でキャラクタ特性を制御するアクティベーションパターン「パーソナベクトル」を特定・操作する手法を論文で報告した（記載日：2025年8月1日）。

パーソナベクトルは、「邪悪さ」「シコファンシー（不誠実なおべっか）」「ハルシネーション傾向」といった特性を示す応答と示さない応答とのニューラル活動の差分として自動パイプラインで抽出される。自動パイプラインは、ある特性（例：邪悪）とその説明を入力とし、対立する挙動を引き出すプロンプトを自動生成したうえで、その応答間の神経活動差分をパーソナベクトルとして特定する。

パーソナベクトルの用途として、(1) 会話中またはトレーニング中にモデルの人格変化を監視する、(2) 望ましくない人格変化を軽減または防止する、(3) そのような変化を引き起こすトレーニングデータを特定する、の3点を実証した。ベクトルをモデルに人工的に注入する「ステアリング」手法で検証が行われ、「邪悪」なパーソナベクトルを注入した場合の挙動変化が出力例として示されている。実証はオープンソースモデルの Qwen 2.5-7B-Instruct と Llama-3.1-8B-Instruct で行われた。

#### [Constitutional Classifiers：ユニバーサルジェイルブレイクへの防御](https://www.anthropic.com/research/constitutional-classifiers)
<sub>anthropic-blog ・ 2026-08-26</sub>
<sub>**原題**: Constitutional Classifiers</sub>

Anthropic の Safeguards Research Team が、AI モデルをユニバーサルジェイルブレイクから防御する手法を記述した論文を公開した（記載日：2025年2月3日）。

Constitutional Classifiers は合成データでトレーニングされた入出力クラシファイアであり、大多数のジェイルブレイクを最小限の過拒否率と小さな計算オーバーヘッドでフィルタリングする設計となっている。

プロトタイプ版では化学・生物・放射線・核（CBRN）分野の特定科学知識の漏洩を防ぐ設定でバグバウンティプログラムを実施した。183名のアクティブ参加者が推定 3,000 時間超にわたってジェイルブレイクを試み、成功した場合の報酬上限は 15,000 ドルとされていたが、2ヵ月間の実験期間中に10件の「禁止クエリ」全件に詳細な回答を引き出すユニバーサルジェイルブレイクを達成した参加者はいなかった。

更新バージョンでは合成評価においても同等の堅牢性を達成しつつ、拒否率の増加を 0.38% に抑え、計算コストの上乗せも小規模にとどめた。Anthropic は、Constitutional Classifiers で防御されたシステムが責任ある拡張ポリシー（RSP）で定める CBRN 能力閾値を超えたモデルのジェイルブレイクリスクを緩和できると述べている。

#### [言語モデルの説得力の測定](https://www.anthropic.com/research/measuring-model-persuasiveness)

<sub>**原題**: Measuring Model Persuasiveness</sub>

Anthropic が言語モデルの説得力を測定する手法を開発し、Claude 1・2・3 の各世代とコンパクト/フロンティア各クラスで比較を行った研究を公開した（記載日：2024年4月9日）。

測定は「主張の提示 → 説得的な論拠の提示 → 同意度の再評価」という3ステップで実施した。クラス内（コンパクト・フロンティアそれぞれ）での世代間比較では、各世代を経るごとに説得力が高まる明確なスケーリング傾向が確認された。最新かつ最高性能モデルの Claude 3 Opus が生成した論拠の説得力は、人間が書いた論拠と統計的に有意な差がないことが報告されている。

#### [AI への核セーフガードの開発](https://www.anthropic.com/research/nuclear-safeguards-for-ai)
<sub>anthropic-blog ・ 2026-08-26</sub>
<sub>**原題**: Nuclear Safeguards for AI</sub>

Anthropic が米国エネルギー省（DOE）の国家核安全保障局（NNSA）と共同で、核兵器に関連する懸念のある会話と無害な会話を識別するクラシファイアを開発し、Claude トラフィックへの導入を完了したと発表した（記載日：2025年8月21日）。予備テストでの精度は96%。

経緯として、2024年4月に Anthropic と NNSA が AI モデルの核拡散リスク評価のためにパートナーシップを締結した。その後1年間、NNSA のスタッフが機密環境で Claude モデルをレッドチームし、その結果を踏まえて NNSA が核リスク指標のリストを Anthropic チームに共有した（このリストは Anthropic チームと共有できる機密分類レベルで作成されている）。

クラシファイア開発のサイクルは、(1) NNSA による核リスク指標リストの提供、(2) Anthropic による懸念ありと無害の合成テストプロンプトの生成とクラシファイア結果の共有、(3) NNSA によるスコアとラベルの整合性検証、(4) フィードバックに基づく改善、という反復プロセスで進められた。早期デプロイデータによると、実際の Claude 会話においてもクラシファイアは良好に機能している。

スパムフィルターと同じく「専門ラベラー」として機能するこのクラシファイアは、核エネルギー・医療・政策に関する正当な議論を通過させつつ、核兵器開発に関わる懸念のある会話を識別する。Anthropic はこの取り組みをフロンティアモデルフォーラムを通じて共有し、他の AI 開発者が NNSA と連携して同様のセーフガードを実装する際のブループリントとして活用できるよう公開する予定。

#### [Claude の悪意ある利用の検出と対処：2025年3月版](https://www.anthropic.com/news/detecting-and-countering-malicious-uses-of-claude-march-2025)
<sub>anthropic-blog ・ 2026-08-26</sub>
<sub>**原題**: Detecting and Countering Malicious Uses of Claude: March 2025</sub>

Anthropic がモデルの悪用事例と対策を共有する最初の脅威インテリジェンスレポートを発表した（記載日：2025年4月23日）。

最も新規性の高い事例として「インフルエンス・アズ・ア・サービス」型オペレーションを紹介した。このオペレーションは Claude をコンテンツ生成のためだけでなく、ソーシャルメディアボットアカウントがいつ・どのコメント・いいね・リシェアを行うかを決定するオーケストレーターとしても使用した点が特徴的で、複数国・複数言語にわたる数万件の一般ユーザーアカウントと接触した。

その他の確認された事例として、(1) セキュリティカメラに関連する公開された認証情報の特定・処理システムの強化とインターネット上のターゲット収集への Claude 活用（成功デプロイは未確認）、(2) 東欧諸国の求職者を標的にした採用詐欺キャンペーンのコンテンツ強化（成功デプロイは未確認）、(3) 技術スキルが限られた個人による通常より高い技術を要するマルウェアの開発（成功デプロイは未確認）が報告された。

主な学習事項として、ユーザーがフロンティアモデルを用いて多数のソーシャルメディアボットを含む複雑な不正システムを半自律的にオーケストレーションし始めており、エージェント型 AI システムの改善に伴いこの傾向が続くと予測している。また生成 AI が、高度な攻撃者のみが実現できていた能力水準での活動を低スキル行為者にも可能にしつつあると指摘した。

#### [Claude Skills とは何か：MCP・Rules・subagent との違いと自作 Skill の作り方](https://qiita.com/yumicat/items/82234f3c77a707d46b52)
<sub>qiita ・ 2026-08-26</sub>

Claude Code の Skills 機能の仕組みと活用法を解説した記事。

Skills は「特定の状況になったときだけ動的に読み込まれる手順書（Markdown ファイル）」であり、SKILL.md ファイルに「いつ使うか（description）」「何をどう進めるか（手順）」「出力フォーマット」を記述する。Claude がユーザーの依頼内容を見て該当する Skill を判断し、必要な時にのみ手順を読み込んで実行する設計（progressive disclosure）となっている。これにより CLAUDE.md に大量の手順を常時読み込ませることなく、大量のノウハウをコンテキスト圧迫なしに保持できる。

他の仕組みとの住み分けは以下の通り：CLAUDE.md（Rules）はプロジェクト全体の前提・ルールを常時コンテキストに読み込む、MCP は外部ツール・データソースへの常時接続、subagent は独立したコンテキストで動く並列実行可能な「作業者」、Skills は繰り返し依頼される定型タスクの「やり方」を必要時のみ動的に読み込む。

既存の Skills は `find-skills`（`skills.sh add find-skills` でインストール）で GitHub 上の公開リポジトリから検索可能。あいまいな要望を投げると Claude が候補を整理し、セキュリティリスク評価（Safe / Low Risk など）も提示する。

Anthropic 公式の `skill-creator` を使った自作 Skill の開発ワークフローとして、意図のヒアリング → SKILL.md ドラフト作成 → eval（評価用タスク）生成 → Skill あり/なしの定量ベンチマーク → フィードバックと改善 → 再ベンチマーク という反復プロセスが紹介された。記事の実例では「長文テキストから X（Twitter）投稿文を生成する Skill」を作成し、Skill なし時の合格率 41%±14% が Skill 導入後に 100%±0% へ向上した（実行時間は 43.5 秒から 91.3 秒に増加）。フィードバックによる Skill の改善として、機械的な改行や言い切り調の文体を緩和する変更が加えられた過程も記述されている。
