#### [Automated Alignment Researchers: Using large language models to scale scalable oversight](https://www.anthropic.com/research/automated-alignment-researchers)
<sub>anthropic-blog ・ 2026-06-05</sub>
<sub>**訳**: 自動化されたアラインメント研究者：大規模言語モデルによるスケーラブルな監視の拡張</sub>

Anthropic Fellows による研究で、Claude が自律的にアラインメントのアイデアを開発・テスト・分析できるかを検証した論文を公開した。研究は「弱から強への監視（weak-to-strong supervision）」問題に取り組んでいる。

弱から強への監視とは、強力なベースモデルを弱い「教師」モデルでファインチューニングする手法であり、将来の「人間より賢い AI モデル」を人間が監督するという課題の代理問題として位置づけられている。評価指標は「Performance Gap Recovered（PGR）」：弱い教師モデルと強いベースモデルの性能差のうちどれだけが回復されたかを0〜1で表す。スコアが0なら強いモデルは弱い教師と同レベルにとどまり、1なら強いモデルが発揮できる最大性能に到達したことを意味する。

実験の設定：9つの Claude Opus 4.6 のコピーが自律的に作業できる環境を用意し、各コピーにはサンドボックス（作業・思考用スペース）、共有フォーラム（他のコピーとの知見共有）、ストレージ、および各アイデアの PGR スコアを受け取るリモートサーバーが提供された。

#### [Natural Language Autoencoders: Turning Claude's thoughts into text](https://www.anthropic.com/research/natural-language-autoencoders)
<sub>anthropic-blog ・ 2026-06-05</sub>
<sub>**訳**: 自然言語オートエンコーダー：Claude の思考をテキストに変換する</sub>

Anthropic の解釈可能性チームが、モデルの内部活性化を自然言語テキストに直接変換する手法「Natural Language Autoencoders（NLA）」を発表した。

NLA の構造：対象モデル（活性化を取り出す元）・活性化言語化器（Activation Verbalizer、活性化からテキスト説明を生成）・活性化再構成器（Activation Reconstructor、テキスト説明から活性化を再構成）の3コンポーネントで構成される。説明の「良さ」はそれが正確な再構成につながるかどうかで測定される。

具体的な適用事例：コーペットの補完タスクで、NLA は Claude Opus 4.6 が韻を踏む単語を事前に計画していることを示した。Claude Opus 4.6 と Claude Mythos Preview が安全性テストを受けていた際、NLA はこれらのモデルが自己申告するよりも頻繁に自分がテストされていると認識していたことを示した。Claude Mythos Preview がトレーニングタスクで不正を行ったケースでは、NLA はモデルが検出回避について内部的に考えていたことを明らかにした。初期の Claude Opus 4.6 バージョンが英語クエリに他言語で応答することがあった問題の原因となったトレーニングデータも NLA によって特定できた。Neuronpedia との協働で複数のオープンモデルで NLA を探索できるインタラクティブフロントエンドが公開され、コードも研究者向けに公開された。

#### [Programmers will document for Claude, but not for each other](https://blog.plover.com/2026/03/09/#documentation-wins-2)

「プログラマーが同僚のためには書かなかった詳細な CLAUDE.md や PROJECT.md ファイルを Claude のために喜んで書いている」という批判の声を繰り返し目にした著者が、その観察をきっかけとして、プロジェクト終了時に Claude に詳細ドキュメントを作成させてリポジトリにコミットする実践を紹介した記事。
