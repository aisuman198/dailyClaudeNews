#### [生物学へのエージェント導入に向けた課題と展望](https://www.anthropic.com/research/agents-in-biology)
<sub>anthropic-blog ・ 2026-06-08</sub>
<sub>**原題**: Agents In Biology</sub>

Anthropic の Laura Luebbert（共同研究者: Ferdous Nasri、Sarah Gurev、Patrick Varilly、Krithik Ramesh、Nuala A. O'Leary、Jonah Cool、Bernhard Y. Renard、Pardis Sabeti）によるブログ投稿。AI エージェントが生物データインフラを利用する際の障壁を論じ、実証実験の結果を報告している。

研究チームは、ウイルス学者がサーベイランスや診断アッセイ開発に用いる NCBI Virus データベースから配列データを取得する作業を、Claude・Biomni・Edison Analysis・GPT という複数の科学研究エージェントに課した。最も強力なモデルでも、信頼できるデータセット構築に必要な精度を安定して達成できなかった。しかし、確定的な検索レイヤーである gget virus を追加したところ、精度がほぼ100%に上昇した。

Luebbert は、現時点では確定的な検索ツールがエージェントのワークフローを信頼性の高いものにするために不可欠であり、生物データベースはエージェントをスケールユーザーとして想定した設計に変えていく必要があると述べている。記事では生物データインフラをナビゲートすることを「自動車登場以前に設計された旧市街を車で走ること」に例えている。固有のファイル形式・分散したデータベース・ワンオフの検索スクリプトが混在した生物系インフラは、エージェントにとって走行しにくい「細い曲がりくねった道」が多い。対してソフトウェアインフラはバージョン管理・文書化された API・パッケージマネージャーなどエージェントに適した構造を持つため、コーディングエージェントは生物系エージェントよりも大きく進歩してきた。

生物・科学ワークフローでは、ゲノムビルドの取り違え・RefSeq と GenBank レコードの混在・セグメント型ウイルスのセグメント名の混同・メタデータフィールドの不整合による記録の欠落といった小さなエラーが、下流の生物学的解釈を無効化する深刻な結果をもたらしうる。エージェントにとっての現在のボトルネックは推論能力だけでなく、生物データをクエリするための広く普及した確定的実行レイヤーが存在しないことにあると結論付けている。

#### [実世界における価値観 — 言語モデルとの実際の会話における価値観の発見と分析](https://www.anthropic.com/research/values-wild)
<sub>anthropic-blog ・ 2026-06-05 ・ 継続話題（3回目）</sub>
<sub>**原題**: Values in the wild: Discovering and analyzing values in real-world language model interactions</sub>

Anthropic Societal Impacts チームによる研究。実世界の会話における Claude の価値表現を大規模に観測・分析した論文の内容を紹介している。

人々が AI に問いかける内容には「新生児のケアで安全性と利便性のどちらを優先するか」「上司との対立で自己主張と職場の調和のどちらを選ぶか」「謝罪メールで説明責任と評判管理のどちらを重視するか」といった価値判断を伴うものが多く含まれる。Anthropic は Constitutional AI やキャラクタートレーニングを通じて Claude の価値観を形成しようとしてきたが、実際の会話でどう表れるかを体系的に観測する手法が必要だった。

研究では、ユーザーの個人情報を除去するプライバシー保護システムを用い、2025年2月の1週間に claude.ai Free および Pro で行われた70万件の匿名化会話をサンプルとして分析した（大多数は Claude 3.5 Sonnet との会話）。純粋に事実的な会話など価値判断を含まない会話を除外した結果、308,210件（全体の約44%）が分析対象となった。会話を個別に分類・要約し、価値観の高レベルな分類体系を提供するアプローチをとっている。研究者がさらなる分析を行えるよう、オープンデータセットも公開している。

#### [自動化されたアライメント研究者 — 弱から強への監督をスケールさせるための LLM 活用](https://www.anthropic.com/research/automated-alignment-researchers)
<sub>anthropic-blog ・ 2026-06-05 ・ 継続話題（3回目）</sub>
<sub>**原題**: Automated Alignment Researchers: Using large language models to scale scalable oversight</sub>

Anthropic Fellows による研究。急速に進歩する LLM に対してアライメント研究を追いつかせるため、AI モデル自体にアライメントのアイデアを自律的に探索・検証させることができるかを実証している。

研究の背景として、フロンティア AI モデルはすでに後継モデルの開発に寄与しているが、アライメント研究者に対しても同様の加速効果を発揮できるかという問いがある。またモデルが人間より賢くなった場合に備えた「スケーラブルな監督（scalable oversight）」はこれまで主に理論的文脈で議論されてきたが、AI の現在の進歩速度を踏まえると実践的な問題になりつつあるとしている。例として、モデルが人間では読解不能なほど膨大で複雑なコードを生成するようになった場合、その挙動が意図通りかどうかを判断することが極めて困難になりうることが挙げられている。

研究では「弱から強への監督（weak-to-strong supervision）」を扱う。弱いモデルが「教師」として、まだファインチューニングを受けていない強いベースモデルに追加のファインチューニングを施す。その後、強いモデルがどれだけ性能を引き出せたかを「Performance Gap Recovered（PGR）」として数値化する。強いモデルが弱い教師と同等の性能しか示せない場合は PGR = 0、弱い教師のフィードバックを活かして理想的な上限性能を達成した場合は PGR = 1となる。この枠組みにおいて弱いモデルは人間の代理、強いモデルは将来の人間より賢い AI の代理として機能する。

実験では Claude Opus 4.6 を9体用意し、それぞれにサンドボックス・他の Claude との知見共有フォーラム・コードアップロード用ストレージ・PGR スコアを受け取るリモートサーバーを付与した上で、各 Claude が自律的にアライメントのアイデアを開発・テスト・分析できるかを検証している。
