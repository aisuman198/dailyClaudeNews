#### [Claude Code v2.1.286 ——&thinsp;--bare 変更とプラグイン制限への対応](https://qiita.com/picnic/items/ae1b6dbd22ba74683b54)
<sub>qiita ・ 0pt ・ 2026-09-30</sub>

Claude Code v2.1.286 は約 80 項目の大型リリースで、以下の 2 つの破壊的変更が中心となっている。

**--bare モードの挙動変更**：(1) 接続する MCP サーバーはコマンドラインで名前を指定したものだけになった、(2) モデルへのシステムリマインダーを一切送らなくなった、(3) バックグラウンドタスクを起動しなくなった、(4) シェルコマンドがタイムアウトすると停止するようになった（バックグラウンドへ移らない）。設定ファイル経由の MCP サーバーや長時間コマンドのバックグラウンド化に依存している CI・スクリプトは動作が変わる可能性がある。

**プラグインのインストール元制限**：サプライチェーン対策として、git リポジトリやローカルフォルダを指す npm ソースのインストールを拒否するようになった。プラグインの依存関係はレジストリのパッケージからのみインストール可能になった。

その他の主な変更点：

- **モデル拒否時の自動フォールバック**：既定モデルや別名の解決先を API が拒否した場合、同じ階層の一つ前のモデルで 1 回だけ再試行するようになった。コンテキストウィンドウが 1M から 200K トークンに縮小する場合はフォールバック通知が表示される
- **秘密情報の秘匿漏れ修正**：MCP エラーメッセージ・ログ・トランスクリプトで認証情報が漏れていた複数のケースを修正（Bearer/Basic 付きキー、パーセントエンコードされたトークン、ゼロ幅スペースを含む秘密情報、URL パスワード内の特殊文字など）
- **verify スキル連携**：`verify` という名前のスキルがプロジェクトまたはユーザーに存在すればコミット直前に自動実行される（ドキュメントのみ・テストのみのコミットは対象外）
- **API 再試行上限の共有**：既定設定では失敗し続ける呼び出しでも最大 14 リクエストまでに収まるようになった
- **利用額メーター修正**：gateway のキャッシュ書き込み単価の計算誤りとサーバー側ツール使用時の入力トークン数え漏れを修正。修正後は表示額が増える可能性がある
- **VS Code 拡張**：ブックマーク・質問履歴・選択肢プレビューを追加。Stop/Escape は現在のターンのみ終了し、バックグラウンドエージェントは継続する
- **Remote Control**：組織ポリシーで無効化されても接続が継続していた問題を修正（通知して切断）
- **Claude Tag**：利用上限ページに「チャンネルを追加」ボタンを追加（プライベートチャンネルも対象）

#### [ロボットはどんな仕事ができるか](https://www.anthropic.com/research/what-work-can-robots-do)
<sub>anthropic-blog ・ 2026-09-30</sub>
<sub>**原題**: What Work Can Robots Do</sub>

Anthropic の経済研究チームが、現在のロボットが米国の職業タスクをどの程度実施できるかを示す「ロボット暴露指数」を発表した。O*NET の約 900 職種・約 1 万 9,000 タスクのデータを用い、Claude がタスクごとの物理的・認知的・対人的要件を評価し、ロボットが実施できる環境によって 4 段階（E0〜E3）に分類した。

**主な発見**：

- 米国の物理的タスクの 74%（全業務時間の 34%）を、ロボットが何らかの環境下で実施できる
- ロボットと LLM を合わせると、全業務時間の約 80% が自動化の対象になる
- コスト面では、ロボットが人間より安価に実施できるタスクは全体の 0.3% にとどまる
- 過去のロボット価格下落トレンドが続くとすると、この割合が 10% に達するには 40 年かかる

**暴露度ランキング**：暴露度が最も高い 10 職種のうち 9 つは車両運転職で、タクシー運転手が暴露指数 2.2 で首位。倉庫作業員・再生資源回収作業員なども高い値を示す。一方、看護師や一般修理職は現行ロボットでは代替困難とされる。

**暴露が高い労働者の特徴**：暴露度上位 20% の労働者は、暴露のない職種の労働者と比較して女性の割合が 20 ポイント低く、学士以上の保有率が 55 ポイント低く、時給が約 30 ドル低い。また失業率は 2 倍以上だった（2020〜2024 年の米国コミュニティ調査データ）。

**歴史的検証**：1977 年以降のデータを用いた後付け検証により、ロボット暴露度が高かった職種ほどその後の数十年で賃金・雇用の低下が大きかったことが確認されており、この指標の将来予測への有効性を裏付けている。

**Dixon の所感**：Dixon は 2023 年に 8 ループまでの計算を達成しており、9 ループへの延長には antipodal duality と form factor を用いた間接的な手法が必要だと考えていた。Claude が直接の bootstrap 計算で 9 ループを解いたことを「直接やるのは難しすぎると思っていたので、かなり印象的だった」と述べた。2 週間かけて Claude の結果を検証した Dixon は、「Claude は私の 2019 年・2023 年の論文を共著者以外のどんな人間よりもよく理解している」と評価しており、Claude の結果を検証することは自分たちのこれまでの研究の検証でもあると表現した。自身が手がけてきた計算が先に AI に解かれた事実について、「魂を砕かれるようなことではない」とも述べている。

**Song He の独立計算**：中国科学院の Song He のグループも 9 ループ振幅の「シンボル」部分を計算しており、GPT-6 を一部の制約計算に活用したが、全体的な枠組みは人間主導で行われた。

**Matt von Hippel の総括**（ゲスト投稿）：Claude が使ったのは既知の手法（bootstrap）であり、96 CPU で 1 週間・計算コスト約 100 ドルで達成した。von Hippel は「専門家が想定していたよりも、まだ取りやすい成果が多く残っている」と述べ、Claude Science が外部の科学的監督なしに 1 回の試行で計算を完遂したことを注目すべき点として挙げた。

#### [GLM-5.3 と高度なサイバー能力の拡散](https://www.anthropic.com/research/glm-5-3-and-the-spread-of-advanced-cyber-capabilities)
<sub>anthropic-blog ・ 2026-09-30 ・ 継続話題（2回目）</sub>
<sub>**原題**: GLM-5.3 and the Spread of Advanced Cyber Capabilities</sub>

Anthropic の Frontier Red Team が、Zhipu AI（中国外では Z.ai として知られる）の GLM-5.3 を分析した報告書。5 か月前に Anthropic が Claude Mythos Preview をエンドツーエンドの高度なサイバーエクスプロイトを自律的に構築できた初めての AI モデルとして Project Glasswing 経由で限定公開したが、同等の能力を持つ GLM-5.3 が実質的に無制限で公開されたと報告している。

**能力評価**：

- ExploitBench（Google Chrome の V8 エンジンの既知脆弱性に対するエンドツーエンドエクスプロイト）：GLM-5.3 は 410 試行中 50 件成功（Claude Mythos Preview は 56 件）
- Binary Exploitation ベンチマーク（OSS-Fuzz プロジェクトのオープンソースソフトウェアへのフルコントロールフローハイジャック）：GLM-5.3 は 4%、Claude Mythos Preview は 6%（Claude Opus 4.6 と GLM-5.2 は 0%）
- NIST CAISI は GLM-5.3 を「これまでに公開された中で最もサイバー能力が高いオープンウェイトモデル」と評価し、米国フロンティアからの遅れは約 4 か月としている

**研究者主導のテスト**：

- 研究者がサンドボックス環境の Linux 版ブラウザに対して GLM-5.3 を使用した結果、JavaScript エンジンに複数の未知の脆弱性が発見され、訪問者のコンピューターから任意ファイルを読み取るエクスプロイトチェーンが構築された（脆弱性は開発元に開示済み）
- GLM-5.3-Flash（小型版）は、Chrome の既知の CVE（CVE-2026-11645）と別の脆弱性を連鎖させた ARM64 向けの信頼性の高いエクスプロイトチェーンを、20 分の人間の作業 + 8 時間の AI 処理・Zhipu API 価格で 20.40 ドルのコストで構築した

**安全策の迂回性**：

- 偽装プロンプト（red-team エージェントとして動作していると伝える）：64% の確率で有害な要求に応じた
- thinking トークンへのプリフィル（API からの操作）：92% の確率で応じた
- abliteration（モデルの拒否挙動の除去）：100% の確率で応じた。abliteration 自体のコストは約 2,200 GPU 時間・約 4,400 ドル。公開から数日以内に複数の開発者が abliteration 済みバージョンを一般公開した

いずれの手法もテスト中の Claude モデルには有効でなかった（偽装プロンプトは Claude の安全策によってブロックされ、Anthropic API は thinking トークンへのプリフィルを許可せず、Claude のウェイトは公開されていないため abliteration 自体が不可能）。

**見解**：Anthropic は「GLM-5.3 は悪意ある行為者がサイバー脆弱性を発見・悪用できる能力を実質的な制限なしに与える」と述べ、Project Glasswing などを通じて防御側への最先端モデルへのアクセス拡大に取り組んでいることを説明した。また各国政府に対し、GLM-5.3 の後継モデルを含む十分な能力を持つ AI モデルへの安全性テスト実施を求めた。

#### [AI に何を望みますか](https://www.anthropic.com/research/your-thoughts-on-ai)
<sub>anthropic-blog ・ 2026-09-30 ・ 継続話題（2回目）</sub>
<sub>**原題**: Your Thoughts On AI</sub>

Anthropic が Anthropic Interviewer を使った公開研究への参加を呼びかけている。研究期間は 2026-09-29〜2026-10-06 で、Claude および Claude Code の Free・Pro・Max ユーザー（アカウント作成から 2 週間以上経過）が対象。インタビューは約 15 分で、AI とのポジティブ・ネガティブな体験、AI に変えてほしい社会の仕組み、AI 企業への要望の 3 点を AI が聞き取る形式。

今回の研究の特徴として、完了後に参加者はインタビュー全文を一般公開するかどうかを選択できる。公開した場合、研究者・政策立案者・ジャーナリストが自由に閲覧・活用でき、Anthropic 以外の誰もが結果を検証できる形になる。一度公開すると Anthropic 側で削除することは可能だが、他者が保存したコピーは削除できないため、意思決定は永続的なものとして扱うよう求めている。

プライバシー上の留意事項として、氏名・メールアドレスは公開しないものの、雇用先・過去のプロジェクト・居住地などの細かい情報の組み合わせから再識別が可能であることを FAQ で明記している。研究者によって Anthropic Interviewer のインタビューからの再識別が可能であることも確認されている。

2025 年 12 月の前回調査では 8 万 1,000 人が参加し、Anthropic Institute の研究アジェンダ策定と世界経済フォーラムでの国際的な意思決定者への発表に活用された。前回は高水準の結果と少数の引用のみが公開されたが、今回は完全なインタビュー記録が公開対象になる。
