リリースと同時に複数の新機能が追加された。claude.ai ではユーザーがタスクへの注力度合いを調整できる機能が加わり、Claude Code には大規模な問題を処理するための「ダイナミックワークフロー」機能が追加された。fast mode（通常の 2.5 倍速で動作）のコストは従来モデル比で 3 分の 1 に引き下げられた。

#### [Agent Skills の発表](https://www.anthropic.com/news/skills)
<sub>anthropic-blog ・ 2026-07-22</sub>
<sub>**原題**: Introducing Agent Skills</sub>

Anthropic が Agent Skills を発表した。Skills は命令・スクリプト・リソースを含むフォルダとして定義され、Claude がタスクに関連性を判断して必要な情報だけをロードする仕組み。

Skills の特性として、コンポーザブル（複数の Skills が自動的に組み合わせて使用される）、ポータブル（Claude アプリ・Claude Code・API 全体で同一フォーマット）、効率的（必要な情報のみをロード）、強力（トークン生成より信頼性の高いタスクには実行コードを含む）の 4 点が挙げられている。

claude.ai では Pro・Max・Team・Enterprise ユーザーが利用可能。タスクに応じて Claude が自動的に該当 Skills を呼び出す。`skill-creator` スキルを使えば、Claude との対話でワークフローを質問しながらフォルダ構成・SKILL.md ファイル・リソースのバンドルまで自動生成できる。API では `/v1/skills` エンドポイントが追加され、カスタム Skills のバージョン管理と管理をプログラムで実行できる（Code Execution Tool beta が必要）。

当初の発表（2025 年 10 月 16 日）後に、組織全体での Skills 管理、パートナーが構築した Skills のディレクトリ、クロスプラットフォーム可搬性のためのオープン標準が追加された（2025 年 12 月 18 日）。

#### [Economic Futures Research Fund への 2 億ドル拠出](https://www.anthropic.com/news/economic-futures-research-fund-agenda)
<sub>anthropic-blog ・ 2026-07-22</sub>
<sub>**原題**: Economic Futures Research Fund Agenda</sub>

Anthropic が Economic Futures Research Fund の研究アジェンダを公開した。同基金に 2 億ドルを拠出し、AI の経済的影響に社会が備えるための外部研究を支援する。

5 つの優先研究領域として以下が掲げられている：企業・職場レベルでの AI の労働者への影響、AI 主導の移行への対応能力の育成、AI による雇用置き換えに向けた所得支援の現代化、混乱が生じる前の AI 主導成長における労働者の利益配分の構築、公共投資に関する新証拠の生成。

大規模 RCT や意欲的・創造的なパイロットプログラム・プログラム評価を対象とし、従来の研究資金・出版サイクルでは追いつかない速度で社会変革が進む AI の現実に対応した研究組織との提携を求めている。研究成果を主要マイルストーンで公開する意思のある研究組織をパートナーとして探しているとしている。

1 年前に開始した Economic Futures プログラムを発展させた取り組みで、多数の小規模助成金の管理が困難だったとの経験から、少数の大型助成金へ焦点を移している。有効な小規模パイロットプログラムをスケールアップできるパートナーとの連携にも関心があるとしている。本文は途中で切れており全文を確認できなかった。

#### [Claude Code v2.1.217: subagent の挙動が大きく変更](https://qiita.com/picnic/items/4d467229dd1d0d4bb96d)
<sub>qiita ・ 2026-07-22</sub>

Claude Code v2.1.217 における subagent 関連の仕様変更を解説した記事。合計 20 件の変更を含むリリースのうち、subagent 関連と企業向けセキュリティ修正が中心。

最大の破壊的変更は、subagent がさらに別の subagent を起動する「ネスト構成」がデフォルトで無効化されたこと。環境変数 `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH` で許可する深さを明示的に設定することで従来の挙動を維持できる。

同時実行 subagent 数の上限がデフォルト 20 件に設定され、超過分はキューに入れられるか制限される。`CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS` 環境変数で上限を変更可能。1 メッセージから大量のバックグラウンドエージェントをファンアウトさせる運用では 20 件を超えたあたりから挙動が変わる可能性があるとしている。

`--max-budget-usd` によるコスト上限がバックグラウンド subagent に適用されていなかった問題が修正された。上限到達後は新規 subagent の生成が拒否され、実行中のバックグラウンド subagent も停止されるようになる。

セキュリティ修正として、シンボリックリンクされた作業ディレクトリのパス正規化が行われず、セッションが指定ワークスペース外に出られてしまう問題が解消された。Claude Desktop のエンタープライズ向けネットワーク設定（mTLS 証明書・TLS 検証・OAuth スコープ・プロキシ設定）が Claude Desktop 経由のセッションで適用されていなかった問題も修正された（影響スコア 70 と高い深刻度）。Windows 自動更新失敗時に `claude.exe` が消失する問題は、失敗時に保全済みの実行ファイルへ自動復元される対応が入った。

#### [Claude Code が入力前に送る 38,000 トークンの実コスト計測](https://qiita.com/ryuhei-kiso/items/b0954846f66d66b6ff20)
