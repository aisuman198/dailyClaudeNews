#### [Claude Mythos Preview のサイバーセキュリティ能力](https://www.anthropic.com/research/mythos-preview)
<sub>anthropic-blog ・ 2026-10-23</sub>
<sub>**原題**: Mythos Preview</sub>

Anthropic は Claude Mythos Preview を発表した。このモデルは主要な OS およびブラウザのゼロデイ脆弱性を自律的に発見・悪用できることが確認された。発見される脆弱性の多くは微妙で発見が困難なものであり、10〜20 年前から存在していたものも多い。確認された中で最も古いものは OpenBSD の 27 年前のバグ（現在はパッチ済み）。悪用コードの例として、4 つの脆弱性を連鎖させてレンダラーと OS のサンドボックス両方を脱出する JIT ヒープスプレーを含む Web ブラウザ用エクスプロイト、Linux での自律的な local privilege escalation（race condition と KASLR バイパス利用）、FreeBSD の NFS サーバー上での RCE（20 ガジェットの ROP チェーンを複数パケットに分割、未認証ユーザーが完全な root アクセスを取得）が挙げられている。

フォーマルトレーニングなしの Anthropic エンジニアが翌朝には完全なエクスプロイトを受け取れた。OSS-Fuzz コーパス内部ベンチマークでは Sonnet/Opus 4.6 がティア 3 を各 1 件しか達成できなかったのに対し、Mythos Preview は完全な制御フローハイジャック（ティア 5）を独立した 10 ターゲットで達成。Firefox 評価では Opus 4.6 が数百回の試行で 2 件だったのに対し Mythos Preview は 181 件の動作するエクスプロイトを生成した。これらの能力は一般的なコード・推論・自律性の改善から副産物として生まれたものであり、サイバー専用のトレーニングによるものではない。Project Glasswing を通じて重要な業界パートナーとオープンソース開発者へ限定公開し、同等能力のモデルが広く利用可能になる前にシステム防御を進める。発見した脆弱性の 99% 超がまだパッチ未適用であり、調整された開示プロセスが進行中。

#### [Claude による暗号アルゴリズムの脆弱性発見](https://www.anthropic.com/research/discovering-cryptographic-weaknesses)
<sub>anthropic-blog ・ 2026-10-23</sub>
<sub>**原題**: Discovering Cryptographic Weaknesses</sub>

Claude Mythos Preview を使った暗号研究で 2 つの重要な成果が得られた。いずれも現行の本番システムへの影響はない。

1 件目は、NIST の耐量子暗号追加募集の第 3 ラウンド候補であるデジタル署名スキーム HAWK への改良攻撃。HAWK が使う格子に「非自明な自己同型（nontrivial automorphism）」という未利用の対称性を発見し、有効な鍵強度を半分にする高速列挙攻撃を可能にした。2 年間の専門家レビューを通過していたが、Mythos Preview が 60 時間の作業で発見した。格子暗号の専門家ではない Anthropic の研究者 1 名が人間の監督者として関与し、他は Mythos が半自律的に作業を進めた。同等のセキュリティレベルを維持するには HAWK の鍵サイズを 2 倍にする必要があり、HAWK が有力な PQC 候補である利点の多くが失われることになる。成果は HAWK の著者に 6 月に共有し、NIST メーリングリストへの公開開示と同時に論文を公開した。

2 件目は AES（ラウンド数を削減した弱化版）への新しい攻撃で、従来の最良攻撃より 200〜800 倍高速化し、攻撃者に必要な推測を 1 つ削減した。こちらは完全自律的な発見。各成果にかかった費用はおよそ 10 万ドル。ETH Zurich・テルアビブ大学・ベルリン工科大学の研究者との共同で CryptanalysisBench を構築・公開した。

#### [Claude とプロパティベーステストによるバグ発見](https://www.anthropic.com/research/property-based-testing)
<sub>anthropic-blog ・ 2026-10-23</sub>
<sub>**原題**: Property Based Testing</sub>

NumPy・SciPy・Pandas などの人気 Python パッケージのバグを自律的に発見するエージェントを開発した研究（2025 NeurIPS Deep Learning for Code Workshop で発表済み、MATS プロジェクトとの連携）。エージェントは Claude Code のカスタムコマンドとして実装され、対象コードを読んでプロパティを推論し、Hypothesis を使ったプロパティベーステストを作成し、テスト結果を自己評価するサイクルを繰り返す。「真のバグを発見したか、テスト自体を調整すべきか」を反省するループが誤検知削減に寄与した。

100 件超の人気 PyPI パッケージを対象に評価を実施し、数百件の潜在的バグを発見。報告前に 3 名の専門家による各 1 時間のレビュー（全員が確信を持った場合のみ報告）という厳格なプロセスを採用。複数のバグレポートをすでに提出済みで、追加検証後に件数を拡大予定。発見データ（無効と判断したものを含む）を公開している。Claude Opus 4.1 と Sonnet 4.5 で自己反省能力の顕著な改善が確認された。

Anthropic は DOE の National Nuclear Security Administration（NNSA）および DOE 国立研究所と共同で、核関連の懸念のある会話と無害な会話を区別するクラシファイアを開発・本番運用中と発表した。予備テストでの総合精度は 96.2%（核兵器クエリの検出率 94.8%、良性会話への誤検知ゼロ）。すでに Claude のトラフィックの一定割合を監視する形で本番展開されており、実世界のデータでも効果が確認されている。

#### [LLM と生物リスク](https://www.anthropic.com/research/biorisk)
<sub>anthropic-blog ・ 2026-10-23</sub>
<sub>**原題**: Biorisk</sub>

Claude Opus 4 のリリース時に AI Safety Level 3（ASL-3）保護を有効化した判断を踏まえ、Anthropic が AI と生物リスク（biorisk）に関する包括的な見解を公開した。Benchling が Claude を研究データ構造化・洞察生成に、Biomni がバイオインフォマティクス解析・実験設計の自動化に Claude を活用している一方、生物リスクへの懸念を説明している。

生物兵器リスクを特に重視する理由として 2 点が挙げられている。①被害の規模：ウイルスを用いた攻撃の影響は初期ターゲットをはるかに超えて拡散しうる。②物質的な障壁の低下：核酸合成のコスト低下・試薬キットの標準化・PCR 機器への容易なアクセスにより材料調達がボトルネックでなくなりつつある。

SecureBio が設計したウイルス学トラブルシューティング評価（VCT）において、Claude は 1 年以内に世界レベルの専門家の基準を下回る状態から余裕をもって上回る状態になった。この評価は専門家が自分の専門分野の問題に答えることを基準にしているため、LLM が複数サブ分野を横断した知識の幅だけでなく専門家を一部の領域で上回っていることを示している。

バイオウェポン取得計画立案の統制試験では、インターネットのみのグループに比べ、セーフガードを無効化した Claude 4（特に Opus 4）へのアクセスがある参加者は大幅に高いスコアと少ない重大な失敗を示した。

#### [Anthropic Economic Index レポート：利用リズムと成果物の分析](https://www.anthropic.com/research/economic-index-june-2026-report)
<sub>anthropic-blog ・ 2026-10-23</sub>
<sub>**原題**: Economic Index June 2026 Report</sub>

Anthropic Economic Index の方法論的アップデートとして、より高いサンプリングレート（時間単位での分析が可能）、会話の成果物を分類する新しいクラシファイアの導入、チャット/Cowork と 1P API を月次で分解した詳細データの公開が行われた。

利用リズムとして、チャット・Cowork での個人的な利用シェアは平日の約 35% から週末の約 50% に上昇する。週末は Claude Code でバックエンドアーキテクチャ・API デバッグ・データストレージ関連が最も減少し、AI エージェント設計・量的取引・ゲームが最も増加する。事業の立ち上げに関する会話も週末に最多となる傾向がある。時間帯別では朝 7 時にニュース関連、10〜11 時にビジネスメールがピーク、午後 6 時にレシピ関連が平均の 2.3 倍、就寝前後の時間帯に睡眠アドバイスが集中する。夜間・週末の仕事関連利用は高賃金職種に偏る傾向がある。米国の確定申告期限（4 月 15 日）前日の 4 月 14 日には税務関連会話が 5 月の平均日の 8 倍に達した。

Claude の会話の 93% が成果物を生成しており、最多は説明（17%）・文書・レポート（15%）・ガイダンス（11%）。2026 年 4 月開始の Anthropic Economic Index Survey の初期結果として、Claude を最も自動化された形で利用している人々が今後 AI がより多くのタスクを担うと見込む一方、賃金・雇用保障・仕事の意味合いへの前向きな影響についても最も楽観的であることが示された。
